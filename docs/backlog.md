## 1. 已知问题（MVP）

| ID | 说明 | 影响 | 缓解 |
| --- | --- | --- | --- |
| K1 | 前端公司切换仅依赖本地 `X-Company-Id`，无完整切换 UI | 多公司演示需改本地存储或 Header | API 已支持 Header；种子可建第二公司 |
| K2 | 汇率固定为 1，无 `exchange_rates` 维护 | 外币场景不可演示 | 模型已预留币种/汇率字段 |
| K3 | 库存无盘点/调拨；可用量与现存量同步 | 仓储场景简化 | 出入库服务可扩展 |
| K4 | 无审批流；草稿直接确认 | 管控偏弱 | 适合 Demo |
| K5 | 幂等种子不清理历史 UT 数据 | 库表随测试增长 | 演示前可重建库或仅看编码主数据 |
